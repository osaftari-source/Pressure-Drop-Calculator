# Pressure Drop Calculator PWA v1.1.2 — Reference-Based Velocity Guideline

## Implemented in this release

- Added selectable **Velocity Guideline Basis** under fluid selection.
- Added recommended velocity references for water services, steam, air, ammonia/refrigerant, organic liquids/oils, natural gas, chlorine, hydrochloric acid, inorganic liquids, and general gases/vapours.
- Added velocity comparison output: calculated velocity, reference basis, and reference range/value.
- Added non-blocking advisory messages for velocities below or above a selected recommended range.
- Retained calculated pressure-drop results even when a velocity warning is shown.

## Reference basis

*Introduction to Process Engineering and Design*, Table 5.1 — Recommended Fluid Velocities.

## Findings not implemented in this release

- Visual differentiation for application pre-filled/example inputs.
- In-app hard refresh / update button.
